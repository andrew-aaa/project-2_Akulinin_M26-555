# primitive_db

Учебный проект: консольное приложение, имитирующее работу с базой данных.
Реализовано на Python 3.12, устанавливается как самостоятельный пакет через `uv`.

## Возможности

- Создание таблиц с типизированными столбцами (`int`, `str`, `bool`).
- Автоматическое добавление первичного ключа `ID:int`.
- Поддержка полного набора CRUD-операций (`Create`, `Read`, `Update`, `Delete`).
- Хранение данных в отдельных JSON-файлах в директории `data/`.
- Централизованная обработка ошибок базы данных (через декоратор `@handle_db_errors`).
- Запрос подтверждения перед выполнением опасных операций (`@confirm_action`).
- Замер времени выполнения запросов с файловой системой (`@log_time`).
- Кэширование `select`-запросов на основе замыканий (`create_cacher`).
- Вывод данных в форматированных таблицах (PrettyTable).

## Управление таблицами

| Команда | Описание |
|---|---|
| `create_table ...` | Создать новую таблицу |
| `list_tables` | Показать список всех таблиц |
| `drop_table` | Удалить таблицу (требует подтверждения) |
| `insert into values (, ...)` | Добавить запись |
| `select from [where = ]` | Прочитать записи по условию или все |
| `update set = where =` | Обновить записи по условию |
| `delete from where =` | Удалить записи (требует подтверждения) |
| `info` | Показать метаданные и количество записей |
| `help` | Справочная информация |
| `exit` | Выход из программы |

**Поддерживаемые типы данных:** `int`, `str`, `bool`.

## Продвинутая функциональность (Декораторы и замыкания)

В проекте реализована архитектура на базе декораторов и замыканий (`src/primitive_db/decorators.py`):

1. `@handle_db_errors`: Автоматически перехватывает и форматирует исключения (KeyError, ValueError, FileNotFoundError), устраняя дублирование блоков `try...except`.

2. `@confirm_action(action_name)`: Запрашивает интерактивное подтверждение в консоли перед выполнением опасных операций (drop_table, delete). Если пользователь вводит `n`, действие отменяется.

3. `@log_time`: Измеряет время работы функций с точностью до миллисекунд и выводит отчет в консоль.

4. `create_cacher()`: Использует замыкание для сохранения результатов выполнения select-запросов. Кэш автоматически сбрасывается при любых изменениях данных (insert, update, delete, drop_table).


### Обработка ошибок

- Неизвестная команда:
  ```
  Функции foobar нет. Попробуйте снова
  ```
- Некорректный столбец (например, неподдерживаемый тип):
  ```
  Некорректное значение: x:float. Попробуйте снова
  ```

## Хранение данных

Метаданные структуры таблиц хранятся в db_meta.json. Записи каждой таблицы сохраняются в отдельных файлах data/.json.
